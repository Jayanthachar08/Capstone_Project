PMRI & Confidence Analysis

In-depth inspection of the Peer-Match Reliability Index (PMRI), negative-control permutation tests, and selective prediction.

PMRI Mathematical Formulation & Component Decomposition
Composite reliability index $PMRI = 0.35 S_{\text{peer}} + 0.30 A_{\text{peer}} + 0.20 C_{\text{cond}} + 0.15 K_{\text{avail}} \in [0.0, 1.0]$
1. Distance Similarity Score ($S_{\text{peer}}$) --
Exponential similarity: $\exp(-d_{\text{mean}} / \tau_s)$ based on standardized Euclidean distance
2. Peer Agreement Score ($A_{\text{peer}}$) --
Trajectory slope agreement: $\exp(-\sigma_{\text{peer}} / \tau_a)$ among matched peers
3. Condition Completeness ($C_{\text{cond}}$) --
Feature completeness and baseline validity across matched peer covariates
4. Candidate Availability ($K_{\text{avail}}$) --
Ratio of valid available reference candidates to target peer size $k=5$

Strict Anti-Leakage Protocol (8 Invariants)
• Strict Batch Partitioning: Batches 1 & 2 (84 cells) used solely for training; Batch 3 (40 cells) held out as primary test set.
• Early-Life Invariance: Zero cycles beyond observation cutoff $N$ used for feature calculation.
• Reference Pool Isolation: Test batteries match peers exclusively from the training reference pool.
• Label Blinding: No EOL, RUL, or target labels used during matching or feature scaling.
• Deterministic Preprocessing: Scalers fitted strictly on training partition and applied out-of-sample.
